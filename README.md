# 百万美金｜谈判与心理博弈桌游

## 游戏信息

- **人数**：3–8 人（网页本地模式：1 名人类玩家 + 2–7 名电脑玩家）
- **时长**：45–90 分钟；数字版可加速
- **年龄**：14+
- **类型**：谈判 / 心理博弈 / 风险决策

## 故事与目标

一群亡命之徒盯上一笔笔百万美元赃款。每轮，所有玩家秘密选择角色并支付保证金。相同角色达到两人即发生撞车，该角色的所有选择者出局；只有唯一选择某角色的玩家能留在车上分赃。

一旦玩家在一轮分赃后达到本局胜利金额，立即获胜。3–4 人局胜利线为 **1500 万**，5–8 人局为 **2000 万**。若 12 张赃物牌耗尽仍无人达线，现金最多者获胜；现金并列时，成功留在车上的轮数较多者胜，仍并列则共享胜利。

## 组件

- 赃物牌 12 张：标示本轮基础赃款、保证金和奖励角色。
- 角色牌：告密者、暴徒、司机、恶棍、谋士。
- 每位玩家一套人物牌；暴徒专属威胁牌 5 张；钞票（100/200/300/500 万）；首领牌。
- 7–8 人局每轮额外加入一张干扰角色牌；该牌参与角色重复数判定，但不是玩家，不持有赃款份额，也不触发角色技能。

## 人数配置

| 人数 | 角色 | 起始现金 | 保证金 | 胜利线 |
|---|---|---:|---|---:|
| 3–4 | 暴徒、恶棍、司机 | 每人 800 万 | 每轮固定 100 万 | 1500 万 |
| 5–6 | 暴徒、恶棍、司机、告密者 | 每人 1000 万 | 按赃物牌 | 2000 万 |
| 7–8 | 全部五种角色 | 每人 1200 万 | 按赃物牌 | 2000 万 |

本局角色集合中不存在的角色不会因干扰牌加入（干扰牌仅从本局可用角色中抽）。角色数量应足够每位玩家各有一张角色牌。

## 一轮流程

### 1. 谋划
1. 翻开一张赃物牌，确认基础赃款、保证金和奖励角色。3–4 人局忽略牌面保证金，统一使用 100 万。
2. 所有玩家秘密且同时选择一张本局可用角色牌。
3. 每人支付本轮保证金；该保证金暂存银行，尚未被没收。
4. 将所有角色牌混洗；翻开玩家人数减一张，最后一张保持暗置。**暗置只隐藏身份，不移出判定**：暗置牌照样计入重复角色，并在后台按实际身份结算技能。7–8 人局加入的干扰牌也参加混洗和角色重复判定，但不代表玩家。

### 2. 谈判
- 可自由公开交谈或私聊、虚张声势、试探、结盟、贿赂。
- 玩家可主动退出本轮，立即取回保证金和角色牌，之后不参与本轮分赃或角色技能；其他玩家仍可继续谈判。
- 当所有仍在本轮的玩家确认不退出时，进入抢劫。玩家间的口头承诺不自动执行；如采用数字版交易工具，只有双方明确接受的即时转账生效。

### 3. 抢劫
按顺序公开/结算角色：**告密者 → 暴徒 → 司机 → 恶棍 → 谋士**。对每个角色计数时，统计仍参与本轮玩家的选择及干扰牌：
- 同角色出现 **2 张及以上**：选该角色的玩家全部撞车出局，保证金没收；干扰牌只影响判定，不对应出局玩家。
- 该角色恰好 **1 张**：选择者留在车上，取回保证金，并有资格分赃、触发相应技能。
- 角色为暗置牌时同样照上述规则判定；仅桌面上暂不公开身份，结算时必须使用该真实身份。

### 4. 分赃
先确定本轮仍在车上的唯一角色玩家，再按以下顺序：
1. **谋士**唯一存活：基础赃款增加 200 万。
2. 所有仍在车上的玩家平分本轮赃款。除法余数留在银行，不分给玩家。
3. **司机**唯一存活：每位其他在场玩家（包括撞车下车者与主动退出者）支付司机 100 万车费。支付额不超过付款者当前可用现金；不足时支付其全部可用现金。若司机是唯一在场玩家，则没有其他车费付款人。
4. **恶棍**唯一存活且暴徒角色玩家仍在本轮（无论暴徒是否撞车）：恶棍从该暴徒玩家处抢走 200 万；若对方当前现金不足则抢走其全部现金。
5. 玩家选择角色与赃物牌奖励角色一致时，额外获得 100 万。奖励只给未退出且未撞车、仍参与本轮的玩家；若奖励角色对应多人撞车，无人获得奖励。
6. **告密者**唯一存活且还有其他仍参与本轮的角色玩家：告密者选择一种仍在场角色，淘汰该角色所有玩家。淘汰玩家已取得的本轮分赃和保证金返还不追回；其之后不参与本轮未结算的角色效果。若告密者是最后唯一在场玩家：不参与分赃，罚款 300 万（现金不足则罚至 0）。

“在场玩家”指本轮开始时没有主动退出的玩家；“仍在场角色”指既未退出也未因撞车出局、且有真实角色牌的玩家。银行现金（保证金没收和分赃余数）不进入任何人的现金。

## 角色技能

| 角色 | 生效条件与效果 |
|---|---|
| 告密者 | 唯一留车且有其他仍在场角色时，可选一种角色淘汰其所有玩家；若只剩自己，不分赃并罚 300 万。 |
| 暴徒 | 不论是否撞车，都取回保证金；唯一留车时获得一张威胁牌。暴徒撞车者仍可取回保证金，但不能分赃或获得威胁牌。 |
| 司机 | 唯一留车时，分赃后向每位其他在场玩家收 100 万车费。 |
| 恶棍 | 唯一留车且暴徒玩家仍在本轮时，从暴徒玩家现金中抢 200 万。 |
| 谋士 | 唯一留车时，本轮赃款增加 200 万。 |

### 保证金结算补充
每名玩家在选择角色后先支付保证金。主动退出者取回保证金。暴徒无论是否撞车都取回保证金。其他撞车玩家保证金没收。唯一留车玩家在分赃前取回保证金。保证金返还不属于赃款，也不计入平分。

## 威胁牌

仅唯一留车的暴徒获得一张威胁牌。持牌者可在之后任意轮谋划阶段使用，查看一名玩家本轮秘密选择的角色；查看后弃置。数字版若无法向本地单机玩家保密该信息，应以私密弹窗展示，电脑玩家不能查看。

## 平局、支付与其他边界

- 现金可以为 0，不允许低于 0。任何支付以当前现金为上限，不足则支付现有全部现金。
- 车费与恶棍抢钱按分赃阶段顺序执行：先车费，再恶棍抢钱，再奖励，最后告密者淘汰/罚款。
- 若同轮达到胜利线的玩家不止一人，按该轮结束现金最高者获胜；现金仍相同则成功留车轮数较多者胜，仍相同共享胜利。
- 若赃物牌刚好用完且有人达到胜利线，优先按即时胜利规则判定；无人达线则按牌堆耗尽规则结束。

## 部署到 Vercel

本仓库提供 Vercel 部署入口：静态页面由 `public/` 提供，NestJS API 通过 `api/index.ts` 运行在 Vercel Function，`GET /api/game/rules` 返回规则说明。导入 Git 项目后，Framework Preset 选 Other，Build Command 使用 `npm run vercel-build`，Output Directory 留空，Install Command 使用 `npm install`。重新部署后，在浏览器开发者工具 Network 检查 `/style.css?v=2` 与 `/game.js?v=2` 响应为 200；若 404，检查 Vercel 项目 Root Directory 指向仓库根目录并重新部署。NestJS API 无状态；当前对局由浏览器处理，只支持本地单机，不支持跨设备联机。

## 可选村规

1. **铁腕退出**：谈判阶段若有人收钱退出，就必须退出，不能收钱后继续留车。本村规只约束明确约定的贿赂。
2. **连坐制**：撞车玩家下轮保证金加倍。
3. **赏金猎人**：每轮额外放置通缉牌，猜中最多人选择的角色者额外获得 200 万（并列规则开局前约定）。

> 以上三项默认关闭。数字版基础模式只实现本规则正文中的流程，不自动执行口头承诺或可选村规。电脑玩家采用本地策略，不需要大模型 API-Key。
