# 百万美金｜网页谈判与心理博弈游戏

本仓库包含《百万美金》网页游戏原型，支持 1 名人类玩家与 2–7 名电脑玩家。后端采用 NestJS 模块/控制器/服务结构，前端为原生 HTML/CSS/JavaScript。目标部署平台为 Vercel，Framework Preset 选择 NestJS。

## Vercel 部署

1. 将本项目推送到 Vercel 已连接的 Git 仓库。Vercel 项目 Framework Preset 选择 **NestJS**，根目录使用项目根目录。根目录 `main.ts` 是 Vercel 的 NestJS 自动检测入口，保留默认 Vercel 路由处理，不额外配置内部 rewrites。
2. Vercel 自动安装依赖并执行 `npm run build`。网页静态文件位于 `public/`，NestJS 应用由根目录 `main.ts` 引导。
3. 在 Vercel Project Settings → Environment Variables 设置 `DEEPSEEK_API_KEY`（推荐）、`DEEPSEEK_BASE_URL`（默认 `https://api.deepseek.com`）和 `DEEPSEEK_MODEL`（默认 `deepseek-chat`），再部署。

无需在本地安装依赖即可提交并交由 Vercel 构建。可选本地开发：Node.js 20+ 下 `npm install && npm run dev`，打开 http://localhost:3000。`npm run build` 用于验证 TypeScript 编译。

## DeepSeek 配置

推荐使用 Vercel 环境变量 `DEEPSEEK_API_KEY`、`DEEPSEEK_BASE_URL`、`DEEPSEEK_MODEL`，使 AI API Key 保存在服务端，不暴露在浏览器。未配置密钥或调用失败时采用演示策略，保证流程可体验。可在新建牌局界面临时覆盖 API 地址和模型名。

## 已实现

- 3–8 人配置、角色集合、初始资金、12 张赃物牌与回合状态。
- 同时选角、混洗后显示玩家人数减一张身份牌，暗置角色照常参与结算。
- 全员公聊，不设私聊；玩家在选角或谈判阶段均可随时跳车。
- AI 单次公开发言最多 30 字；电脑玩家轮流发言，整体间隔至少 5 秒。被点名时会先公开回复“我在，正在思考。”；人类玩家跳车后，电脑将在 10 秒内自动确认发车。全员确认后按角色逐步揭晓，再展示分赃结算。
- 语言协议不产生自动效果；电脑会参考可见承诺、对话、人设与当前利益判断交易请求，不再随机一律接受/拒绝。
- 电脑玩家使用简短代号，并根据人格轮流参与全桌公聊；人类发言在界面先行即时回显。
- 玩家全部确认后结算撞车、保证金、司机车费、恶棍抢钱、奖励、谋士增赃与胜利判定。
- DeepSeek 电脑玩家决策接口及可配置人设；无 API 配置时回退演示策略。

## 当前原型说明

该版本是单浏览器、本地内存牌局原型，服务器重启后牌局不持久化；还未提供多人联网房间、账号、威胁牌组件以及完整告密者选择 UI。交易金额为双方提交并接受的即时转账，接受时再次校验现金。尚未实现的原规则细节可在后续迭代中补齐。

## 桌游规则

### 游戏信息、目标与配置

- 3–8 人（本网页本地模式：1 名人类玩家 + 2–7 名电脑玩家），谈判 / 心理博弈 / 风险决策。
- 每轮秘密选角并支付保证金。相同角色达到两人即发生撞车，该角色的所有选择者出局；只有唯一选择某角色的玩家能留在车上分赃。
- 3–4 人局胜利线为 1500 万，5–8 人局为 2000 万。若 12 张赃物牌耗尽仍无人达线，现金最多者获胜；现金并列时，成功留车轮数较多者胜，仍并列则共享胜利。
- 3–4 人角色：暴徒、恶棍、司机；每人起始 800 万，保证金固定 100 万。5–6 人角色再加入告密者；每人起始 1000 万，保证金按赃物牌。7–8 人加入谋士；每人起始 1200 万。7–8 人局每轮额外加入一张干扰角色牌；它参与角色重复数判定，但不代表玩家、不持有赃款份额，也不触发技能。本原型尚未完整实现干扰牌效果。

### 每轮流程

1. 翻开赃物牌；3–4 人局忽略牌面保证金，统一使用 100 万。
2. 所有玩家秘密且同时选择一个本局可用角色，支付保证金。混洗所有角色牌；翻开玩家人数减一张，最后一张暗置。暗置身份仍计入重复角色并按真实身份结算。
3. 谈判期间可自由公开交谈、私聊、虚张声势、试探、结盟、贿赂。玩家可主动退出本轮，立即取回保证金和角色牌，之后不参与分赃或角色技能。
4. 语言协议只代表承诺，不会由系统自动执行，可能违约；实际交易请求可在确认发车前任何时刻向特定目标发起，只有接收方明确接受后才生效，按接受时现金即时结算。电脑守信倾向由人设和策略控制。
5. 所有仍参与玩家确认发车后，按告密者 → 暴徒 → 司机 → 恶棍 → 谋士顺序结算。角色出现两张及以上则玩家全部撞车出局，保证金没收；恰好一张则玩家留车、取回保证金并可触发技能。暴徒无论是否撞车都取回保证金。
6. 唯一存活谋士令基础赃款增加 200 万；剩余留车者平分赃款，余数留在银行。唯一存活司机在分赃后向每位其他在场玩家收 100 万车费，按付款者可用现金封顶。
7. 唯一存活恶棍且暴徒玩家仍在本轮时，从该暴徒抢走 200 万，现金不足则抢走全部。选择角色与赃物牌奖励角色一致的未退出、未撞车玩家额外获得 100 万。
8. 唯一存活告密者可选择一种仍在场角色，淘汰该角色所有玩家；已得分赃和返还保证金不追回。若告密者是最后唯一在场玩家，不参与分赃并罚款 300 万（现金不足则罚至 0）。

所有支付以当前现金为上限，不允许现金低于 0。车费与恶棍抢钱按此顺序执行，再发奖励，最后告密者淘汰/罚款。同轮多人达胜利线时比较该轮结束现金，再比较成功留车轮数，仍并列共享胜利。
